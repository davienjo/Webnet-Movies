# WebNet Movies (Learning Project)

## Description
WebNet Movies is a responsive web application created as a learning project, inspired by Netflix. Built with HTML, and CSS it demonstrates layout replication, interactive UI elements, and design principles. This project was a practice exercise to improve my frontend development skills and understanding of modern web interfaces.

## Technologies Used
- HTML
- CSS

## Features Implemented
- layout for desktop only  
 
 

- Practice replicating Netflix design home page

## Learning Goals
- Improving CSS layout and responsiveness  

- Understanding UI/UX replication of popular websites  
- Experimenting with design, spacing, and modern web aesthetics
